C++ PRACTICAL EXAM - ALL SETS
================================

Contains 14 separate C++ source files for SET-1, SET-2, SET-3, SET-4,
SET-5, SET-6 and SET-7.

How to compile (g++):
    g++ filename.cpp -o program
    ./program

On Windows:
    g++ filename.cpp -o program.exe
    program.exe

Each question is in its own .cpp file. Open the required file in Code::Blocks,
VS Code, Dev-C++, or another C++ compiler.

Note:
- SET-2 Result uses total >= 120 as the pass condition because the paper
  does not specify a pass mark.
- SET-4/SET-5 use virtual inheritance to solve the diamond problem.
