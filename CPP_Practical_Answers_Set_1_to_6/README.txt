C++ PRACTICAL EXAM ANSWERS - SET 1 TO SET 6

Each SET folder contains two separate C++ programs (Q1 and Q2).
These are written in simple, student-friendly C++.

How to compile and run (g++):
    g++ Q1_Student.cpp -o output
    ./output

On Windows:
    g++ Q1_Student.cpp -o output.exe
    output.exe

Notes:
- Enter input when the program asks for it.
- Some questions do not specify exact formulas/rates, so simple sample values
  are used (for example, interest rates and rental charges).
- Set 1 Q1 demonstrates the static count, array, friend function, object array,
  and a function declared outside the class using scope resolution.
